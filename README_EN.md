# FRP Bar–Concrete Bond Strength Prediction Platform — Final v1.0

Both desktop and mobile interfaces are fully English.

Surface configurations: HW = helically wound; Rb = ribbed; In = indented.
FRP types: CFRP = carbon-fibre-reinforced polymer; GFRP = glass-fibre-reinforced polymer; BFRP = basalt-fibre-reinforced polymer.

The user-provided final icon is used for the application header, browser favicon, Apple home-screen icon and web-app manifest.

Scope: This tool is intended solely for theoretical analysis, research support and parametric comparison of FRP bar–concrete bond strength. Predictions should not replace design codes, structural design checks, construction acceptance, safety assessment or professional engineering judgement. Inputs outside the database ranges constitute extrapolation and should be interpreted with caution.
